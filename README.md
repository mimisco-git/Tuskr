**Live:** https://tuskr-eight.vercel.app

## What is Tuskr?

Tuskr is a next-generation NFT marketplace built natively on Sui and Walrus. Every NFT minted on Tuskr has its media permanently stored on Walrus — a decentralized storage network — with the ownership record secured on Sui. Users can also generate NFT concepts using AI, upload their own artwork, browse the entire Sui NFT ecosystem, and trade collections — all in one place.

---

## Hackathon Tracks

### Walrus Track
Every NFT minted on Tuskr stores its image on Walrus via the Walrus Publisher API. The resulting blob ID is written directly into the NFT's on-chain fields at mint time. Anyone can independently verify the media exists permanently at:

```
https://aggregator.walrus.space/v1/blobs/{blobId}
```

This gives NFTs on Tuskr a provable, permanent media layer that standard IPFS-based NFTs cannot guarantee.

### Agentic Web Track
Tuskr's AI NFT Generator uses Groq's inference API to generate creative NFT concepts — name, description, style, and traits — from a simple text prompt. The generated concept guides the user through the minting process, creating a fully agentic NFT creation workflow entirely on-chain on Sui.

## How It Works

### Minting Flow
1. User uploads artwork (or generates with AI)
2. Tuskr uploads the file to Walrus via our serverless proxy
3. Walrus returns a `blobId` — permanent content address
4. Tuskr calls the `tuskr_nft::mint` Move function on Sui with the `blobId` embedded
5. The NFT lives on Sui with a permanent Walrus media reference

### AI Generator Flow
1. User describes their NFT concept in plain text
2. Groq AI generates a structured concept: name, description, style, traits
3. User uploads their artwork
4. Single-click mint to Sui with Walrus storage

### Marketplace Flow
1. Browse all Sui NFT collections via TradePort API
2. Click any collection to see its NFTs, floor price and volume
3. Mint Tuskr-native NFTs and list them for sale
4. Buy listed NFTs directly through the Tuskr marketplace contract

## Run Locally

```bash
# Clone
git clone https://github.com/mimisco-git/Tuskr.git
cd Tuskr

# Install
npm install

# Environment variables
cp .env.example .env
# Fill in your keys (see below)

# Run
npm run dev
```

## Verifying Walrus Storage

Every NFT minted on Tuskr has a Walrus blob ID on-chain. To verify any NFT's media is permanently stored:

```
https://aggregator.walrus.space/v1/blobs/{blobId}
```

Replace `{blobId}` with the blob ID from the NFT's on-chain data. The media file will be returned directly from the Walrus network.
